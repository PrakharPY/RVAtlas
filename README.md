# RVAtlas

Generate a single texture atlas from multiple OBJ materials while automatically remapping UV coordinates.

## Features

✔ OBJ parser

✔ MTL parser

✔ Automatic texture discovery

✔ MaxRects texture packing

✔ Automatic UV remapping

✔ Atlas generation

✔ CLI interface

✔ Reverse engineering friendly
